─── Retrieving auto-generated secrets ───

FalkorDB password:

  kubectl get secret {{ include "sbom-graph.falkordb.secretName" . }} \
    -n {{ .Release.Namespace }} \
    -o jsonpath='{.data.password}' | base64 -d; echo

Webhook HMAC secret (generate once, configure in Sonatype Lifecycle Admin → Webhooks):

  ./scripts/generate-webhook-secret.sh --k8s-secret {{ .Release.Namespace }} {{ include "sbom-graph.webhookSecret.secretName" . }}

  Or retrieve the value Helm stored in Secret {{ include "sbom-graph.webhookSecret.secretName" . }}:

  kubectl get secret {{ include "sbom-graph.webhookSecret.secretName" . }} \
    -n {{ .Release.Namespace }} \
    -o jsonpath='{.data.webhook-secret}' | base64 -d; echo

  Sonatype must send header:  X-Nexus-Webhook-Signature: sha256=<HMAC-SHA256 hex digest of body>

{{- end }}
  In-cluster:          http://{{ include "sbom-graph.releaseListener.clusterHostname" . }}{{ .Values.ingress.webhookPath | default "/webhook" }}

Sonatype API credentials (outbound SBOM fetch) — pre-create Secret {{ include "sbom-graph.sonatype.secretName" . }}:

  kubectl create secret generic {{ include "sbom-graph.sonatype.secretName" . }} \
    -n {{ .Release.Namespace }} \
    --from-literal=sonatype-username='<iq-user>' \
    --from-literal=sonatype-password='<iq-pass>'

  Chart uses releaseListener.sonatype.existingSecret (default sbom-graph-sonatype) so Helm
  does not try to adopt a manually created Secret. Local dev: set existingSecret="" and pass
  --set releaseListener.sonatype.username=... --set releaseListener.sonatype.password=...
